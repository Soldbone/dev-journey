# CChat
CChat은 C언어로 채팅 프로그램을 만들어 보는 토이 프로젝트입니다.
별다른 교육 자료 없이, 생성형 AI의 도움을 받아 2주 정도의 기간 안에 완성하는 것이 목표입니다.

## Chapter 1.
Echo Server 만들기: client가 보낸 메시지를 그대로 반환하는 server 만들기

## Chapter 2.
1:1 채팅 만들기: 키보드 입력과 상대방의 메시지 읽기를 동시에 수행하기 위해 thread 사용해보기(fork 대신 pthread 쓰면서 Java thread 미리 맛보기)

## Chapter 3.
다자간 채팅 만들기: main thread, worker thread, broadcasting, mutex 개념 배우기
